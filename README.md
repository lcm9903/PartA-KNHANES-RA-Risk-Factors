# 국민건강영양조사로 본 류마티스관절염 연 요인 (KNHANES RA Associated Factors)

> 한국 성인에서 류마티스관절염 의사진단과 흡연·비만·전신 염증(hs-CRP)의 연관성을 분석하고, 일반 건강검진 변수로 진단 여부를 얼마나 구분할 수 있는지 통계 모델과 머신러닝을 비교했습니다.

**구성**: **파트 A(관찰 연관성)** → 파트 B(2표본 멘델리안 무작위분석으로 인과 검증)

---

## 1. 연구 질문

1. 류마티스관절염 진단자는 비진단자와 비교해 흡연, BMI, hs-CRP가 다른가?
2. 나이·성별 등을 보정한 뒤에도 그 연관성이 남는가?
3. 이 변수들로 진단 여부를 나이·성별만 쓴 모델보다 더 잘 구분할 수 있는가?

## 2. 데이터

| 항목 | 내용 |
|---|---|
| 자료 | 국민건강영양조사 제7기 3차년도(2016-2018) 기본DB `hn18_all` |
| 대상 | 만 19세 이상 성인 중 류마티스관절염 문항 응답자 **5,990명** (진단 112명, 1.87%) |
| 회귀분석 | 주요 변수 결측 제외 완전자료 5,730명 (진단 103명) |
| 변수 정의 | 「국민건강영양조사 제7기(2016–2018) 원시자료 이용지침서」 기준 |

> ⚠️ 원시자료는 질병관리청 국민건강영양조사 누리집에서 이용 신청 후 내려받을 수 있으며, 재배포가 허용되지 않아 이 저장소에는 포함하지 않았습니다.

### 주요 변수 처리

| 변수 | 원자료 | 처리 |
|---|---|---|
| 결과 | `DM3_dg` | 류마티스성 관절염 의사진단 여부 (0/1만 사용, 8·9 제외) |
| 흡연 | `BS1_1`, `BS3_1` | 지침서 현재흡연율 정의에 따라 현재 / 과거 / 비흡연으로 재분류. `BS3_1`=8(비해당)은 결측이 아닌 **비흡연** |
| 음주 | `BD1_11` | 1년간 음주빈도(1~6). 8(평생 비음주)은 1(최근 1년 안 마심)로 처리 |
| hs-CRP | `HE_hsCRP`, `HE_hsCRP_etc` | 측정 하한(0.15 mg/L) 미만 657명은 0.075로, 20 mg/L 초과는 20.01로 대치 후 자연로그 변환 |
| 교란변수 | `age`, `sex`, `HE_BMI`, `edu`, `ho_incm` | 교육·소득은 4범주 |
| 가중치 | `wt_itvex` | 유병률 추정에만 사용. 3개년 통합 시 조사구수 비율(각 1/3) 적용 |

## 3. 방법

1. **기술통계**: 연속형은 Welch t-검정, 범주형은 카이제곱 검정
2. **가중 유병률**: 건강설문-검진조사 가중치 적용
3. **로지스틱 회귀** (흡연 기준범주 = 비흡연)
   - 모델 1: 나이 + 성별
   - 모델 2: + 흡연, BMI, 음주, 교육, 소득
   - 모델 3: + log(hs-CRP)
   - 성별 층화 분석
4. **머신러닝 비교**: 로지스틱 회귀 vs LightGBM, 5겹 층화 교차검증
   - 결측 대치·표준화를 Pipeline 안에 넣어 **데이터 누수 방지**
   - 불균형 자료(유병률 약 2%)라 AUROC와 함께 **AUPRC** 보고
   - 나이·성별만 쓴 기준 모델과 비교
5. **SHAP**: LightGBM 예측에 대한 변수 기여도 시각화

## 4. 결과

### 4.1 유병률

| | 가중 유병률 |
|---|---|
| 전체 | 1.50% |
| 남성 | 0.73% |
| 여성 | 2.25% |

### 4.2 단순 비교 (진단군 vs 비진단군)

| 변수 | 진단군 | 비진단군 | p |
|---|---|---|---|
| 나이 (평균) | 63.2세 | 51.3세 | <0.001 |
| 여성 비율 | 79.5% | 56.0% | <0.001 |
| BMI (평균) | 23.8 | 24.0 | 0.62 |
| hs-CRP (중앙값) | 0.60 mg/L | 0.46 mg/L | 0.012 (로그값 t-검정) |
| 현재흡연 | 10.8% | 18.1% | 0.003 (흡연 3범주) |

단순 비교에서는 진단군의 흡연율이 오히려 낮았습니다. 진단군에 흡연율이 낮은 **여성과 고령자가 많아서 생긴 교란**으로 보입니다.

### 4.3 로지스틱 회귀 (모델 3, 완전 보정)

| 변수 | OR (95% CI) | p |
|---|---|---|
| 나이 (1세) | 1.04 (1.02–1.06) | <0.001 |
| 여성 | 2.87 (1.45–5.68) | 0.002 |
| 현재흡연 (vs 비흡연) | 1.29 (0.61–2.75) | 0.51 |
| 과거흡연 (vs 비흡연) | 0.98 (0.45–2.14) | 0.96 |
| BMI (1 kg/m²) | 0.95 (0.89–1.01) | 0.12 |
| **log(hs-CRP)** | **1.24 (1.05–1.46)** | **0.013** |

- 보정 후 흡연의 방향은 위험 증가 쪽으로 바뀌었지만 통계적으로 유의하지 않았습니다.
- hs-CRP는 보정 후에도 연관성이 남았습니다. log(hs-CRP) 1 증가(CRP 약 2.7배)당 진단 오즈가 약 24% 높았습니다.
- 성별 층화에서 hs-CRP 연관성은 여성(OR 1.26, 95% CI 1.05–1.53)에서 유지됐고, 남성은 진단자가 22명뿐이라 추정이 불안정했습니다.

### 4.4 예측 성능 (5겹 교차검증)

| 모델 | AUROC | AUPRC |
|---|---|---|
| 나이 + 성별만 | 0.733 | 0.052 |
| 로지스틱 회귀 (전체 변수) | 0.732 | 0.049 |
| LightGBM (전체 변수) | 0.713 | 0.066 |
| 무작위 기준선 | 0.500 | 0.019 |

변수를 더하거나 비선형 모델을 써도 **나이·성별만 쓴 모델보다 구분 능력이 거의 나아지지 않았습니다.** 일반 건강검진 변수만으로는 류마티스관절염 진단자를 구분하기 어렵다는 뜻입니다.

ROC·PR 곡선은 `roc_pr.png`, SHAP 요약 그림은 `shap_summary.png`에 저장됩니다.

## 5. 해석과 한계

- **단면 자료라 인과를 말할 수 없습니다.** hs-CRP가 높은 것은 질환의 원인이라기보다 질환 활동성의 결과일 가능성이 큽니다(역인과). 진단 후 금연이나 체중 변화도 흡연·BMI 연관성을 흐릴 수 있습니다.
- **자가보고 진단**이라 골관절염과의 혼동 등 오분류 가능성이 있습니다.
- **표본 수**: 단일 연도로는 진단자가 약 110명이라 신뢰구간이 넓습니다. 특히 남성 분석이 불안정합니다.
- **복합표본 설계**: 회귀와 머신러닝은 연관성·예측 비교가 목적이라 가중치 없이 수행했습니다. 모집단 추정치의 정확한 표준오차를 내려면 층(`kstrata`)·집락(`psu`)을 반영한 분석이 필요합니다.
- **CRP 하한 대치**: 0.15 mg/L 미만을 0.075로 둔 선택에 대한 민감도 분석이 필요합니다.
- **SHAP 값**은 모델 예측에 대한 기여도이지 인과 효과가 아닙니다.


**주요 라이브러리**: pandas, scipy, statsmodels, scikit-learn, LightGBM, SHAP, matplotlib
